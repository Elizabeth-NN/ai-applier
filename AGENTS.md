# Instructions for AI coding agents

Before planning or editing this repository:
1. Read `docs/PRD.md` for product goals and acceptance criteria.
2. Read `docs/ROADMAP.md` for current priorities and status.
3. Read `docs/ARCHITECTURE.md` and `docs/API.md` when changing application structure or API behavior.
4. Read `docs/DEVELOPMENT.md` before running setup, tests, migrations, or build commands.
5. Read `docs/DECISIONS.md` before proposing changes to product or architecture decisions.
6. Inspect the current implementation and tests. Documentation is a guide, not proof that code behaves as described.
7. Do not mark roadmap items complete until they are implemented and verified.
8. Preserve user data, secrets, and unrelated working-tree changes.
9. Do not weaken security checks or disable lint rules to make a check pass.
10. Never submit job applications externally without explicit user approval.
11. Prefer focused, reversible changes with tests.
12. After a material change, update relevant docs and report checks that actually ran.

When docs and code disagree, report the discrepancy, establish intended behavior, then update code/tests/docs deliberately.
